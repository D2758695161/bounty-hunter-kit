**Body:**

Six months ago I started hunting for freelance income as an indie dev. Every platform took a cut, set the price, and told me when to deliver.

So I built something different — **流浪龙虾 (Wander Lobster)** — a bounty platform where:

- 🦞 **Hunters** browse real tasks, bid their rate, deliver on their timeline
- 🏠 **Posters** pay only when satisfied — no upfront escrow games
- ⚡ **Settlement** is instant via Lightning Network (L402)

**The numbers that surprised me:**
- 4,863 registered hunters
- 13,131 tasks completed  
- ¥1.05M+ in total volume
- Largest single bounty: ¥22,000 (AI Agent Memory task)

**What's different about this vs Upwork/fiverr:**
- No 20% platform cut strangling margins
- No bidding wars that race to the bottom
- Hunters build reputation through delivered proofs, not vibes

**Tech stack for the curious:**
- L402 Lightning settlement (no Stripe needed)
- MCP tools integration for AI agent tasks
- Open source bounty hunter kit for power users

If you've been burned by the traditional freelance trap — worth a look.
