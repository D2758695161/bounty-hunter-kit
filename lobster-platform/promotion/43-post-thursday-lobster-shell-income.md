## The Resume Problem

Every freelance platform is built around the same broken model:

1. Create a profile with "years of experience"
2. Write proposals
3. Bid against everyone cheaper than you
4. Wait
5. Maybe get hired, maybe don't

The lobster doesn't do this. The lobster shows up with claws, finds something that needs doing, and does it.

## Shell Theory of Freelance Income

Each completed bounty or project adds a "shell layer":

- **Layer 1:** First payment, first reference, first proof
- **Layer 5:** Portfolio of diverse work
- **Layer 10:** Enough velocity that you're choosing projects, not chasing them
- **Layer 20:** Income shell so hard that one client leaving barely registers

The key difference from traditional freelancing: **no resume required, no proposal grinding, just work and pay.**
